## Utiliser un asset

```gdscript
var node := AssetLibrary.instantiate("market_stall")   # Node3D (PlaceableAsset)
add_child(node)
node.position = Vector3(2.0, 0.0, 4.0)                 # multiple de 0,20 m = aligné sur la grille

# Beaucoup d'éléments : PropScatter (MultiMesh par cellule, LOD, collisions regroupées)
var scatter := PropScatter.new()
add_child(scatter)
scatter.add_asset("garden_fence", Transform3D(Basis.IDENTITY, Vector3(1, 0, 0)))
scatter.commit()
```

L'origine d'un asset est le coin minimum de son emprise, au sol (`ground_y` pour l'embarcadère). Les arbres sont centrés sur leur tronc. Rotation par pas de 90°.

## Créer un nouvel asset

1. Écrire un script `build(args)` qui renvoie un `VoxelAsset` (outils : `AssetKit` pour les objets à 2 cm, `BuildingKit` pour les bâtiments à 10 cm).
2. L'enregistrer dans `scripts/assets/asset_registry_lot3.gd`.
3. `godot --headless -s tools/bake_assets.gd -- <id>` ; aperçu : `tools/sheet.gd` ou `tools/preview_asset.gd`.
4. Respecter `docs/DIRECTION_ARTISTIQUE.md` (règle des pixels de 2 cm, motifs signatures).
