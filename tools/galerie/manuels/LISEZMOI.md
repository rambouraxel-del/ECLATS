# Modèles ajoutés à la main

Pour montrer dans la galerie un modèle qui n'est pas produit par un générateur du jeu :
déposer ici `mon_modele.glb` et `mon_modele.json` :

```json
{"nom": "Mon modèle", "categorie": "Décor", "glb": "mon_modele.glb", "dimensions_m": [1.2, 0.8, 0.8]}
```

Puis `tools/galerie.sh` : le modèle apparaît dans le filtre « Manuels ».
